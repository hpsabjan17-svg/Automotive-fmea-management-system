Automotive FMEA Management System

A web-based Automotive FMEA Management System designed to manage DFMEA, PFMEA, product structure, functional analysis, key characteristics, functional linking, control plans, and project reports in one place.

Features

- Project Management
- Functional Analysis
- Boundary Diagram
- Product Structure
- Key Characteristics
- Functional Linking
- Design FMEA (DFMEA)
- Process FMEA (PFMEA)
- Control Plan
- Project Reports
- Excel Report Export
- Print / PDF Report

Technology Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- OpenPyXL

Purpose

The system provides a centralized platform for organizing automotive FMEA activities and connecting product functions, components, failure analysis, and process controls.
